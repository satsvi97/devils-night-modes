# Фоны режимов

Положить сюда свои фоны — по одному на книгу. Имена строго такие:

```
corrupt.jpg      Corrupt      (спортзал, маска, огонь)
hideaway.jpg     Hideaway     (коридор отеля, доберман)
killswitch.jpg   Kill Switch  (церковь, витраж, пуанты)
punk57.jpg       Punk 57      (синий, граффити, гитара)
conclave.jpg     Conclave     (яхта, океан, шампанское)
nightfall.jpg    Nightfall    (заброшенный парк, карусель)
```

Можно `.png` — тогда поменяй расширение в `style.css`
(блок `--dn-photo` у нужного режима).

## Как это работает

Фон ложится **под** тонировку и силуэты сцены, поэтому автоматически
попадает в палитру режима: темнеет, подкрашивается, силуэты (карусель,
витраж, черепа) остаются поверх.

Если файла нет — слой просто не рисуется, тема остаётся на чистом CSS.
Ничего не ломается.

## Размер

1920×1080 хватает с запасом (`background-size: cover`).
Вес: до ~1 МБ на файл, лучше jpg качества 80–85.
